# Транслятор учебного конфигурационного языка в XML

Дисциплина «Конфигурационное управление», домашняя работа, вариант 23.
Группа ИКБО-66-25.

## 1. Общее описание

Инструмент командной строки переводит текст на учебном конфигурационном
языке в текст на языке XML. Входной текст берётся из файла, путь к которому
задаётся ключом `--input`, результат выводится в стандартный вывод.
Синтаксические ошибки выявляются с выдачей сообщений.

Для синтаксического разбора используется специализированный инструмент
[Lark](https://github.com/lark-parser/lark): грамматика языка записана
в файле `src/grammar.lark`, по ней Lark строит LALR-парсер.

### Как устроена трансляция

    текст ──Lark──> дерево разбора ──> AST ──> значения ──> XML
                    (syntax.py)                (evaluator.py) (xml_writer.py)

1. `syntax.py` разбирает текст по грамматике и превращает дерево разбора
   Lark в простое дерево (AST): числа, словари, объявления констант.
2. `evaluator.py` выполняет объявления `let` сверху вниз и подставляет
   значения констант вместо `#(ИМЯ)`.
3. `xml_writer.py` записывает итоговое значение в XML.

### Структура проекта

    src/
      main.py          точка входа, ключ --input
      grammar.lark     грамматика языка для Lark
      syntax.py        синтаксический разбор, тексты синтаксических ошибок
      evaluator.py     вычисление констант и словарей
      xml_writer.py    вывод в XML
      errors.py        исключение TranslatorError
    tests/             автотесты (unittest)
    examples/          два примера конфигураций
      errors/          примеры с ошибками
    scripts/           запуск тестов и демонстрации
    requirements.txt   зависимость: lark
    run.sh             запуск транслятора

## 2. Функции и настройки

### Запуск

    sh run.sh --input ФАЙЛ
    sh run.sh -i ФАЙЛ

| Ключ | Описание |
|------|----------|
| `-i`, `--input` | путь к файлу с конфигурацией (обязательный) |
| `-h`, `--help` | справка |

Код возврата: 0 при успехе, 1 при ошибке в конфигурации или файле,
2 при неверных аргументах командной строки.

### Синтаксис языка

| Конструкция | Синтаксис | Пример |
|-------------|-----------|--------|
| число | `[+-]?\d+` | `42`, `-15`, `+7` |
| имя | `[A-Z]+` | `PORT`, `TIMEOUT` |
| словарь | `struct { имя = значение, ... }` | `struct { A = 1, B = 2 }` |
| объявление константы | `let имя = значение;` | `let PORT = 8080;` |
| вычисление константы | `#(имя)` | `#(PORT)` |

Значение — это число, словарь или `#(имя)`. Словари могут быть вложены
друг в друга на любую глубину; словарь может быть пустым (`struct {}`);
запятая после последней пары разрешена. Пробелы и переводы строк между
элементами не важны.

Файл состоит из объявлений констант `let` (их может не быть) и одного
итогового значения в конце:

    let PORT = 8080;
    let LIMITS = struct { MIN = -5, MAX = 5 };
    struct {
        PORT = #(PORT),
        LIMITS = #(LIMITS),
    }

### Константы

Константы вычисляются на этапе трансляции. Объявления выполняются сверху
вниз: значение сразу вычисляется и запоминается, а `#(имя)` подставляет
его. Константа может использовать константы, объявленные выше. Константа
может быть числом или словарём; словарь подставляется целиком.

### Вывод в XML

Корневой элемент называется `config`. Каждый ключ словаря становится
элементом с тем же именем, число становится текстом элемента, пустой
словарь — пустым элементом:

    <?xml version="1.0" encoding="UTF-8"?>
    <config>
      <PORT>8080</PORT>
      <LIMITS>
        <MIN>-5</MIN>
        <MAX>5</MAX>
      </LIMITS>
    </config>

Знак `+` у числа в выводе не сохраняется: `+5` выводится как `5`.

### Сообщения об ошибках

Ошибки выводятся в стандартный поток ошибок с номером строки и столбца.

| Ситуация | Пример сообщения |
|----------|------------------|
| недопустимый символ | `строка 2, столбец 5: недопустимый символ «p»; ожидалось: «}», имя (большие латинские буквы)` |
| пропущена запятая | `строка 3, столбец 5: неожиданный элемент «HOST»; ожидалось: «,», «}»` |
| пропущена `;` после `let` | `строка 2, столбец 1: неожиданный элемент «struct»; ожидалось: «;»` |
| дробное число | `строка 2, столбец 14: недопустимый символ «.»; ожидалось: «,», «}»` |
| словарь не закрыт | `строка 1, столбец 14: неожиданный конец файла; ожидалось: «,», «}»` |
| константа не объявлена | `строка 3, столбец 14: константа PROT не объявлена` |
| константа объявлена дважды | `строка 2, столбец 5: константа PORT уже объявлена` |
| имя повторяется в словаре | `строка 3, столбец 5: имя PORT повторяется в словаре` |
| нет файла | `файл не найден: config.conf` |

## 3. Сборка и тесты

Нужен Python 3.9 или новее и библиотека Lark:

    python3 -m pip install -r requirements.txt

Сборка не нужна. Команды:

    sh run.sh --input examples/web_server.conf   запуск транслятора
    sh scripts/run_tests.sh                      автотесты
    sh scripts/demo.sh                           все примеры и ошибки

Тесты покрывают все конструкции языка с учётом вложенности: числа со знаком
и без, пустые и вложенные словари, запятую в конце, константы-числа и
константы-словари, константы из других констант, `#(имя)` во вложенных
словарях и на верхнем уровне, вывод в XML, ключ `--input` и все ошибки.

## 4. Примеры использования

### Пример 1. Веб-сервер (`examples/web_server.conf`)

Настройки сервера, прокси, кэша и журнала. Порт, таймаут и лимиты вынесены
в константы и подставлены в несколько мест.

    let HTTPPORT = 8080;
    let TIMEOUT = 30;
    let LIMITS = struct {
        CONNECTIONS = 1000,
        REQUESTS = 50,
        BODY = 10485760,
    };

    struct {
        SERVER = struct {
            PORT = #(HTTPPORT),
            WORKERS = 4,
            TIMEOUT = #(TIMEOUT),
            LIMITS = #(LIMITS),
        },
        PROXY = struct {
            PORT = 80,
            TARGET = #(HTTPPORT),
            TIMEOUT = #(TIMEOUT),
        },
        ...
    }

Результат (начало):

    $ sh run.sh --input examples/web_server.conf
    <?xml version="1.0" encoding="UTF-8"?>
    <config>
      <SERVER>
        <PORT>8080</PORT>
        <WORKERS>4</WORKERS>
        <TIMEOUT>30</TIMEOUT>
        <LIMITS>
          <CONNECTIONS>1000</CONNECTIONS>
          <REQUESTS>50</REQUESTS>
          <BODY>10485760</BODY>
        </LIMITS>
      </SERVER>
      <PROXY>
        <PORT>80</PORT>
        <TARGET>8080</TARGET>
        <TIMEOUT>30</TIMEOUT>
      </PROXY>
      ...
    </config>

### Пример 2. Умный дом (`examples/smart_home.conf`)

Комнаты с температурой и освещением, диапазон уличной температуры
(отрицательные числа и числа со знаком `+`), пустой словарь для гаража
без освещения.

    let COMFORT = 22;
    let NIGHT = 18;
    let LAMP = struct {
        BRIGHTNESS = 70,
        COLOR = 3000,
    };

    struct {
        HOUSE = struct {
            FLOORS = 2,
            OUTSIDE = struct {
                MIN = -25,
                MAX = +35,
            },
        },
        ROOMS = struct {
            KITCHEN = struct {
                TEMPERATURE = #(COMFORT),
                LIGHT = #(LAMP),
            },
            ...
            GARAGE = struct {
                TEMPERATURE = +5,
                LIGHT = struct {},
            },
        },
        ...
    }

Результат (фрагмент):

    $ sh run.sh --input examples/smart_home.conf
    <?xml version="1.0" encoding="UTF-8"?>
    <config>
      <HOUSE>
        <FLOORS>2</FLOORS>
        <OUTSIDE>
          <MIN>-25</MIN>
          <MAX>35</MAX>
        </OUTSIDE>
      </HOUSE>
      <ROOMS>
        <KITCHEN>
          <TEMPERATURE>22</TEMPERATURE>
          <LIGHT>
            <BRIGHTNESS>70</BRIGHTNESS>
            <COLOR>3000</COLOR>
          </LIGHT>
        </KITCHEN>
        ...
        <GARAGE>
          <TEMPERATURE>5</TEMPERATURE>
          <LIGHT />
        </GARAGE>
      </ROOMS>
      ...
    </config>

### Ошибка в конфигурации

    $ sh run.sh --input examples/errors/unknown_constant.conf
